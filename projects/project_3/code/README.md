## Overview

This repository contains a **complete, modular, and fully reproducible
implementation** of **Project 3**, comparing five machine learning
approaches on two real-world time-series tasks:

### Tasks

1.  **Regression** - Predict next-hour household electricity
    consumption\
    → Dataset: [UCI Individual Household Electric Power Consumption](https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption)
    (2006-2010)

2.  **Classification** - Predict whether bilateral trade between two
    countries will grow more than 10% next year\
    → Dataset: [Correlates of War Bilateral Trade v4.0](https://correlatesofwar.org/data-sets/bilateral-trade/) (1870-2014)

### Methods Compared

-   Classical: OLS, Ridge, Lasso, Logistic Regression
-   Tree-based: XGBoost (Regressor & Classifier)
-   Neural Networks: From-scratch Feed-Forward Neural Network
-   Deep Learning: LSTM (PyTorch)
-   Proper **chronological train/validation/test splits**

## Quick Start

### 1. Clone the Repository

``` bash
git clone git@github.com:chrisatrotter/FYS-STK3155.git
cd projects/project3/code
```

### 2. Create Virtual Environment

``` bash
python3 -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate         # Windows
```

### 3. Install Dependencies

``` bash
pip install --upgrade pip
pip install -r requirements.txt
```

if on MacOS, then remember to install, `libomp` for the `XGBoost Library`:


``` bash
brew install libomp
```

### 4. Run the Full Project

``` bash
python project3.py
```

This will:
- Load and preprocess both datasets
- Train all models (XGBoost, FFNN, LSTM, etc.)
- Generate 14+ publication-quality figures
- Save results and plots automatically

### Run a Specific Part Only

``` bash
python project3.py --part a
python project3.py --part c
python project3.py --part d
```

## Command-Line Arguments
| Argument   | Type | Default | Description              |
|------------|------|---------|--------------------------|
| `--seed`   | int  | 1993    | Random seed              |
| `--epochs` | int  | 300     | Training epochs          |
| `--batch`  | int  | 256     | Mini-batch size          |
| `--part`   | str  | none    | Run only part a, c, d    |
